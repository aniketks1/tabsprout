Privacy Policy

Last Updated: October 20, 2026

Introduction

TabSprout ("we", "our", or "the extension") is an open-source browser extension designed to help users organize open browser tabs into native Chrome tab groups. We are committed to transparency and respecting your privacy.

TabSprout runs entirely inside your browser. All clustering, domain parsing, and tab management algorithms execute 100% locally on your computer. No data is ever transmitted to remote servers.

Information Access & Handling

To provide its core functionality, TabSprout accesses the following temporary data during active sorting operations:

  • Tab URLs and Titles: Read locally in volatile system memory to extract website domain names, identify search engine queries, and evaluate user-defined project matching rules. This data is never written to disk or transmitted anywhere.
  • Tab Group Metadata: Read and created locally via the Chrome Tab Groups API to assign group names, labels, and color properties.

Zero Remote Data Transmission

We do not collect, log, store, sell, or transfer your personal data, web history, or browsing activity:

  • No analytics or telemetry scripts are included in the extension.
  • No tracking pixels, cookies, or identifier tokens are utilized.
  • No third-party advertising frameworks or external SDKs are loaded.
  • No remote code execution (eval or external script tags) is used, complying with Manifest V3 policies.

Local Settings Storage

User preferences (such as selected grouping strategy, custom project rules, excluded domains, and theme choices) are saved using Chrome's native chrome.storage.sync API.

This configuration data remains private to your personal browser profile and synchronizes exclusively through your authenticated Google account if Chrome Sync is enabled on your device. We have no access to this data.

Browser Permissions Justification

TabSprout requests the minimum set of permissions necessary to deliver its single purpose:

  • tabs: Required to query open tabs in the current window to determine their URLs and titles for local grouping.
  • tabGroups: Required to create, color, label, and collapse native Chrome tab groups.
  • storage: Required to persist user configuration and project rules across browser restarts.

Third-Party Services

The extension does not communicate with any external APIs or third-party web services. When visiting the project's documentation or GitHub repository, the standard privacy policies of GitHub apply.

Children's Privacy

TabSprout does not collect personal information from any user, including children under the age of 13.

Changes to This Policy

We may periodically update this Privacy Policy to reflect improvements or changes in browser platform policies. Any updates will be posted to this page with an updated revision date.
